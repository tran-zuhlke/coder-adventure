# Coder Adventure

A 3D roguelike where a coder fights bugs, testers, BAs, POs and clients across 6 worlds, rescues the team, and survives Layoff Season.

**Play:** open the GitHub Pages URL for this repo (Settings → Pages).

## Controls
WASD move · Mouse aim · LMB attack/fire · RMB block (melee) / roll (ranged) · F ultimate · R potion · T autofire · Esc pause

## Saves
Progress is stored in each player's own browser (localStorage). Nothing is uploaded; clearing site data resets it.

## Tech
three.js (bundled into game.js), custom toon + ink-line post-processing. Models, textures and sound effects are CC0 assets.
